# 浙大·AI思政课一点通 · 体验预览

这是无需登录即可浏览的公开界面预览，保留产品欢迎页、手机布局、会话外观、来源详情和静态人物形象。点击“查看示例”可体验预先撰写的非私密问答；所有示例均明确标识，不冒充实时模型回答或权威知识库资料。

本预览不连接问答后端，不收集或上传输入内容，没有账号凭据、真实会话、学生资料、数字人模型或 SDK。文件上传、语音和数字人口播暂不可用。完整在线服务仍需后端部署及相关能力授权。

所有资源采用相对路径，可部署到 GitHub Pages 项目路径。入口为 `index.html`；`.nojekyll` 保持原样发布。`SHA256SUMS.txt` 是发布内容的 SHA-256 清单（清单本身不自列）。

公开文件范围：index.html、app.js、styles.css、logo.png、avatar.jpg、README.md、.nojekyll、SHA256SUMS.txt。logo 与静态人物形象由产品方提供并授权用于本次预览。
